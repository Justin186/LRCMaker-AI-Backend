# LRC-Maker AI 辅助对齐（本地计算引擎）

基于 Whisper 语音识别模型的本地歌词打轴引擎，配合 [LRC-Maker](https://lrc-maker.github.io/) 的波形图界面使用，可实现“AI 自动对齐 + 网页可视化微调 + KTV 逐字动感预览”的工作流。它适合需要快速生成初稿、再进行精细校准的歌词制作场景。

## 快速开始

> **说明**：本仓库为**源码版**，需要自行配置 Python 环境后直接运行，暂无独立 exe 打包版可用。

### 1. 配置 Python 环境并启动本地 AI 引擎

本地引擎负责实际的语音识别与对齐，需要 Python 3.9+ 环境。

1. **安装 Python**（3.9 及以上），建议使用 [Miniconda](https://docs.conda.io/en/latest/miniconda.html) 或 [Anaconda](https://www.anaconda.com/) 创建独立环境。
2. **创建并激活虚拟环境**（可选但推荐）：
   ```bash
   conda create -n lrcmaker python=3.10 -y
   conda activate lrcmaker
   ```
3. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
   > 若你有 NVIDIA 显卡并希望启用 GPU 加速，请额外安装对应 CUDA 版本的 PyTorch，例如：
   > ```bash
   > pip install torch --index-url https://download.pytorch.org/whl/cu121
   > ```
4. **启动引擎**：
   ```bash
   python api_server.py
   ```
5. 当终端显示 `✅ AI 引擎就绪！` 时，说明启动成功。（*注：如果默认的 8000 端口被占用，程序会自动顺延启用新端口并在终端中醒目提示，请留意日志。*）

> **模型说明**：首次启动时若本地 `models` 目录下没有对应模型，引擎会自动从网络下载（默认 `small` 规格，约 500MB）。你也可以手动下载模型放入 `models/faster-whisper-<规格>` 目录实现完全离线运行。模型规格、GPU 开关等可在 `api_server.py` 顶部的可配置项中调整。

### 2. 安装浏览器插件管理器
为了让网页与本地引擎通信，需要先安装脚本管理器。

* 推荐使用 Edge 或 Chrome 浏览器。
* 安装 [Tampermonkey（油猴插件）](https://www.tampermonkey.net/)。

### 3. 安装专属脚本
本仓库支持两种前端接入方式，脚本源码均存放在本仓库的 `script/` 文件夹下：

#### 方式 A：LRC-Maker 网页版（油猴脚本）
* 由于歌词格式的变动，[Greasy Fork 上的原版脚本](https://greasyfork.org/zh-CN/scripts/579199-lrc-maker-ai-%E8%BE%85%E5%8A%A9%E5%AF%B9%E9%BD%90-%E9%85%8D%E5%90%88%E6%9C%AC%E5%9C%B0%E5%BC%95%E6%93%8E) 已无法适配，请改用本仓库 `script/` 文件夹下的脚本，并通过 Tampermonkey 手动导入使用。
* 脚本源码：`script/LRC-Maker AI 辅助对齐 (配合本地引擎)-2.1.txt`，可自行修改后导入。
* 安装完成后，浏览器侧的准备工作就结束了。

#### 方式 B：网易云音乐客户端（BetterNCM 插件）
除了网页版，本仓库还适配了网易云音乐客户端的 AI 逐字歌词功能，通过 [Refined Now Playing](https://github.com/MicroCBer/RefinedNowPlaying) 这个 BetterNCM 插件实现：

1. 安装 [BetterNCM](https://github.com/MicroCBer/BetterNCM) 插件框架。
2. 安装 [LibFrontendPlay](https://github.com/MicroCBer/LibFrontendPlay) 插件（用于获取当前播放音频）。
3. 安装并启用 **Refined Now Playing** 插件（前端源码见 [refined-now-playing-netease](https://github.com/MicroCBer/RefinedNowPlaying) 仓库）。
4. 在网易云音乐 → 设置 → 歌词中勾选「AI 逐字歌词」。
5. 切换歌曲即可自动触发 AI 逐字歌词对齐。

> 该方式会从当前播放的歌曲获取音频与歌词，连同每行参考时间戳一起发送到本地引擎，从而启用**分段对齐**能力，对长间奏歌曲的对齐效果更佳。

## 使用方式

### 方式 A：LRC-Maker 网页版

1. 确保本地 AI 引擎窗口处于运行状态。
2. 打开 [LRC-Maker 官网](https://lrc-maker.github.io/)。
3. 页面左下角会出现 **AI LRC 生成器** 面板，可按 `Alt + A` 快捷键显示或隐藏。
4. 在左侧点击 **加载音频**，导入歌曲文件。
5. 在 AI 面板中粘贴纯文本歌词，工具会自动处理作词、作曲等非演唱内容。
6. **(全新特性)** 选择你需要的输出模式：「普通单句 LRC」或「逐字动感 KTV」。
7. 点击 **🚀 一键 AI 强制对齐**。
8. 等待处理完成后，歌词会自动写入编辑区。如果你选择了 KTV 模式，可以直接在面板上方的视窗中体验原生渲染的逐字高亮预览！

### 方式 B：网易云音乐客户端

1. 确保本地 AI 引擎窗口处于运行状态。
2. 打开网易云音乐，播放任意歌曲。
3. 在设置 → 歌词中勾选「AI 逐字歌词」。
4. 切换歌曲时，插件会自动从当前播放的歌曲获取音频与歌词，连同参考时间戳发送到本地引擎进行对齐。
5. 对齐完成后，逐字歌词会自动应用到播放界面，并可通过 `lyrics-updated` 事件提供给其他插件。

## 核心特性

### 🎮 GPU 加速（自动检测）
引擎会自动检测 NVIDIA GPU 并启用 CUDA 加速推理（`float16` 精度），大幅提升对齐速度；未检测到 GPU 时自动回退到 CPU 模式（`int8` 精度）。可在 `api_server.py` 顶部的可配置项中调整模型规格与 GPU 开关。

### 🌐 多语种自动识别
引擎会自动检测歌词语言，支持 **中文、英文、日文、韩文、俄文、泰文** 等多种语言的强制对齐，无需手动指定语言。

### 🎯 基于参考时间戳的分段对齐
针对**长间奏**歌曲（如副歌间有较长纯音乐段落）导致整段对齐漂移的问题，引擎支持传入每行歌词的参考时间戳，自动将歌词按间奏断点分段，逐段独立对齐，显著提升长间奏歌词的对齐准确性。

### 📝 请求日志记录（可选）
可在 `api_server.py` 中开启 `ENABLE_REQUEST_LOG`，将每次对齐请求的源文本与输出 LRC 记录到 `logs/align_requests.log`，便于排查与复盘。

### ✨ 稳定的逐字 KTV 格式
逐字动感模式采用稳定的 `[行起始]词1[词1结束]词2[词2结束]` 格式，并自动处理跨行分词与句中停顿标记，保证 KTV 预览的流畅与准确。

## 常见问题

**Q:点击对齐后提示“生成失败 / 请检查本地 API 服务器是否启动”怎么办？**

A:首先检查本地引擎的黑框窗口是否仍在运行。其次，查看黑框里的启动日志，如果提示默认的 8000 端口被占用并切换到了 8001 或其他端口，**请务必在网页 AI 面板的配置中，将 API 端口同步修改为对应的新端口。**

**Q:歌词中的作词、作曲等信息会被当成歌词一起处理吗？**

A:不会。只要这些信息是类似 `作词：张三` 或 `作曲: 李四` 的格式，脚本会自动识别并将其视为非演唱内容。如果你想更明确地区分正文与说明，也可以在正片歌词前加一行 `---`，其上方内容会被统一视为说明信息。

**Q:第一次启动需要等待很久吗？还需要联网下载模型吗？**

A:源码版首次启动时，如果本地 `models` 目录下没有对应模型，会自动从网络下载（默认 `small` 规格，约 500MB），需要联网等待一段时间。如果你希望完全离线运行，可以手动下载模型放入 `models/faster-whisper-<规格>` 目录，之后即可离线秒开。若你不想折腾，也可以直接使用作者发布的独立 exe 打包版（已内置模型）。

**Q:我的电脑有 NVIDIA 显卡，能加速吗？**

A:可以！引擎会自动检测 NVIDIA GPU 并启用 CUDA 加速，对齐速度会大幅提升。如果你有独立显卡，也可以在 `api_server.py` 顶部的可配置项中把 `MODEL_SIZE` 调整为 `medium` 或 `large-v3` 以获得更高的识别精度（GPU 上推荐）。未检测到 GPU 时会自动回退到 CPU 模式。

**Q:支持哪些语言的歌词对齐？**

A:引擎会自动识别歌词语言，支持中文、英文、日文、韩文、俄文、泰文等多种语言，无需手动指定。

**Q:遇到长间奏的歌曲，对齐结果会漂移吗？**

A:新版引擎支持基于参考时间戳的分段对齐。当歌词带有每行参考时间时，引擎会自动按间奏断点分段、逐段独立对齐，能有效避免长间奏导致的整段时间漂移问题。

**Q:如果不再使用，如何清理本地文件和模型？**

A:源码版会在 `~/.lrc_maker_models` 目录缓存下载的模型。如果不再使用，删除本仓库文件夹，并清理 `~/.lrc_maker_models` 缓存目录即可。若你使用的是作者发布的独立 exe 打包版，则只需删除解压出来的整个文件夹即可，不会残留垃圾。
